効果音について
==============

本作の効果音（ドン.wav / カッ.wav / suzu.wav）は、フリー素材を使わず、
すべて tools/make_se.py で合成して生成しています。

  ドン.wav   和太鼓の面打ち（0.97秒）
             190Hz から 78Hz へ急速に下降するピッチ包絡（打面の張力変化）を核に、
             円形膜の非調和モード（ベッセル関数の零点比 1.593 / 2.135 / 2.295）、
             バチのアタック音、胴の空気鳴りを重ねて合成。

  カッ.wav   縁打ち（0.54秒）
             2600Hz と 1250Hz のバンドパスノイズに木部の共振（760Hz / 1130Hz）を
             加え、30〜45ms で減衰させた乾いた音。

  suzu.wav   スレイベル「シャン」（0.28秒・ステレオ）
             小さな鈴が房になって鳴る音のため、正弦波を重ねるのではなく
             ノイズを多数の高Qバンドパスに通す方式で合成した。
             ・5k〜11kHz に散らした14個の共鳴体（鈴1個ずつに対応）
             ・鳴り出しを0〜8ms ずつずらし、玉が擦れる立ち上がりを作る
             ・左右で鈴の配置を変えてステレオの広がりを出す
             ・低域を持たせず、太鼓のドンと帯域が重ならないようにしている

再生成する場合:
    cd tools
    python make_se.py

numpy と標準ライブラリのみで動作します。第三者の音源は使用していません。

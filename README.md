# クロス・ノーツ

**異なったインターフェースによって対戦可能な音楽ゲーム**

手持ちの MIDI ファイルを読み込んで譜面を自動生成し、
「プロセカ風の4レーン落ちゲー」と「太鼓の達人風の2種叩き分け」という
操作感の違う2つのスタイルで遊べる音楽ゲーム。
2人プレイでは**この2つを混ぜて対戦できる**のが最大の特徴で、
片方が4レーン・もう片方が太鼓、という噛み合わない勝負が成立する。

Python + pygame 製。曲は MIDI 音源で鳴らすので、MIDI さえあれば何でも譜面になる。

```
python game.py     # play/ フォルダで実行
```

初回セットアップと必要ファイルの置き方は **[docs/SETUP.md](docs/SETUP.md)** を参照。

## 特徴

### 1. 2つのプレイスタイル

| モード | 操作 | 内容 |
|---|---|---|
| **プロセカ風** | 4レーン (D / F / J / K) | 上から降ってくるノーツを、落ちてきたレーンのキーで叩く |
| **太鼓の達人風** | 2種類 (内側 F・J = ドン / 外側 D・K = カッ) | 右から流れてくるノーツを、色に応じて叩き分ける |

判定は **Just / Good / Miss** の3段階。判定ラインからのズレが小さいほど Just。
コンボ・最大コンボ・Just 数・Good 数がリザルトに出る。

### 2. インターフェースをまたいだ対戦

2人プレイでは、P1 と P2 が**それぞれ別のスタイルと難易度**を選べる。
同じ曲・同じ音を、片方は4レーンで、片方はドン/カッで捌く。

- **P1**: A / S / D / F
- **P2**: L / ; / : / ]

競う項目も選べる:

| 項目 | 勝敗の決め方 |
|---|---|
| 仲良くプレイする | 勝敗なし。並んで叩くだけ |
| 最大コンボ数 | 最大コンボが多いほう |
| Just 数 | Just 判定が多いほう |
| 合計 Hit 数 | Just + Good が多いほう |
| サドンデス | HP 20 スタート。Miss で減り、先に 0 になったほうが負け |

ソロには **ノーマル** と **HP モード**（Miss で HP が減り、0 で強制終了）がある。

### 3. 好きな MIDI がそのまま譜面になる

`play/music/` に置いた `.mid` が選曲画面に並ぶ。譜面は実行時に生成される。

- MIDI の Note On を時刻[秒]に変換し、**平均音高以上の音**＝主旋律だけをノーツにする
- 難易度 Easy / Normal / Hard は**同時刻とみなす幅**（0.5 / 0.15 / 0.1 秒）で、
  狭いほど音を拾ってノーツが増える
- 曲そのものは `pygame.midi` の MIDI 出力で鳴らす

### 4. レーン配置を機械学習で決める（AI 譜面生成）

**このゲームで機械学習を使っているのはここ。**

4レーンのどのキーに置くかは、元は `random.randint(0, 3)` の完全な乱数だった。
つまり配置が音楽とも運指とも無関係で、「押しにくいだけの譜面」になっていた。

そこで、**人間が作った実譜面（osu!mania 4K）を教師にした GRU** に置き換えた。
「直前に叩いたレーン」と「前の音からの間隔」から次のレーンを予測し、
それを1音ずつ自分の出力に戻していく（自己回帰生成）。

結果として、ルールで書き下すのが難しい**人手の癖**——左右交互打ち、トリル、
階段——が配置に出るようになり、乱数配置より格段に叩ける譜面になる。

プロセカ風モードを選ぶと、生成前に **temperature 調整画面**が入る:

| temperature | 生成される譜面 |
|---|---|
| `0.0` | 最尤。規則的で読みやすいが単調 |
| `1.0`（既定） | 学習した確率そのまま。**人手の譜面に最も近い** |
| `1.5` | 揺らぎ大。崩れた配置が混ざる |

↑↓←→ で調整、Enter で決定。決定後、生成中はロード画面が出る。

モデルの構造・学習データ・入出力の詳細は **[docs/ML.md](docs/ML.md)**。
自分で学習し直す手順は **[docs/TRAINING.md](docs/TRAINING.md)**。

## 操作方法

### メニュー

| 画面 | 操作 |
|---|---|
| タイトル | `Enter` でスタート |
| 曲選択 | `↑` `↓` で選択、`Enter` で決定 |
| 各種モード選択 | 数字キー `1` `2` … |
| temperature 調整 | `↑` `→` で上げる / `↓` `←` で下げる / `Enter` で決定 |

### プレイ中

| | プロセカ風 | 太鼓の達人風 |
|---|---|---|
| **ソロ** | `D` `F` `J` `K`（左から順に） | ドン = `F` `J` / カッ = `D` `K` |
| **2P - P1** | `A` `S` `D` `F` | ドン = `S` `D` / カッ = `A` `F` |
| **2P - P2** | `L` `;` `:` `]` | ドン = `;` `:` / カッ = `L` `]` |

`Esc` で中断。リザルト画面では `R` でタイトルに戻る、`Esc` で終了。

## ゲームの流れ

```
タイトル
  └ 曲選択（play/music/ の .mid）
      └ 1人 / 2人
          └ プレイスタイル選択（プロセカ風 / 太鼓の達人風） ※2人なら P1・P2 別々
              └ 難易度選択（Easy / Normal / Hard）
                  └ temperature 調整   ← プロセカ風を選んだときだけ
                      └ 譜面生成（GRU 推論・ロード画面）
                          └ ソロモード選択 / 対戦項目選択
                              └ プレイ → リザルト
```

## リポジトリ構成

```
.
├── play/                    遊ぶのに必要なもの一式
│   ├── game.py                  ゲーム本体（ここで python game.py）
│   ├── chart_ai_osu.py          学習済みモデルでレーンを生成する推論ヘルパ
│   ├── osu_lane_model.keras     学習済み GRU
│   ├── osu_dataset.npz          学習データ（推論時は間隔バケット境界を参照）
│   ├── ドン.wav / カッ.wav / suzu.mp3   効果音
│   └── music/                   ★ 遊ぶ曲(.mid)を自分で置く
│
├── train/                   学習し直すときだけ使う
│   ├── parse_osu.py             osu_data/ の .osu → 学習データ
│   ├── train_osu_GRU.py         学習データ → 学習済みモデル
│   ├── osu_learning_curve.png   学習曲線
│   └── osu_data/                ★ 教師にする実譜面(.osu)を自分で置く
│
└── docs/
    ├── SETUP.md             インストールとファイルの置き方
    ├── TRAINING.md          モデルを学習し直す手順
    └── ML.md                モデルの中身
```

★ の2つは第三者の著作物になるため、このリポジトリには**含めていない**。
遊ぶだけなら `play/music/` に MIDI を入れるだけでよく、学習済みモデルは同梱してある。

## 動作環境と制限

- Windows / Python 3.11、`pygame` `mido` `numpy` `tensorflow` `tf-keras`
- フォントに Windows のシステムフォント **meiryo** を使うため、Windows 前提
- 曲の再生に **MIDI 出力デバイス** を使う（Windows 標準の GS Wavetable Synth など）
- **曲中で BPM が変わる MIDI は非対応**（起動時に検出して終了する）
- MIDI トラック中の楽器は先頭2つまでを対象にする
